# 测试用例文档

本文档记录问卷系统的测试用例，包括测试步骤、输入、预期输出和实际结果。所有测试均基于 pytest 自动化测试框架，使用 mongomock 模拟 MongoDB。

## 测试环境

| 项目 | 版本 |
|------|------|
| Python | 3.13.2 |
| Flask | 3.0.0 |
| pytest | 8.2.0 |
| mongomock | 4.3.0 |
