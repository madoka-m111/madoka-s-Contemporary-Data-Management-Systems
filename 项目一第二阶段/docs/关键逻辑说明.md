# 关键逻辑说明

本文档说明问卷系统的核心业务逻辑实现，包括认证授权、问卷生命周期、题目管理、跳转逻辑、答案校验、填写流程和统计逻辑。

## 1. 认证授权逻辑

### 1.1 用户注册
- 接口：`POST /api/auth/register`
- 逻辑：
  1. 校验用户名、邮箱、密码均非空
  2. 检查用户名是否已存在（`users` 集合唯一索引）
  3. 检查邮箱是否已注册（`users` 集合唯一索引）
  4. 使用 `werkzeug.security.generate_password_hash` 对密码进行 bcrypt 加密存储
  5. 将用户文档插入 `users` 集合
  6. 返回 JWT access token

### 1.2 用户登录
- 接口：`POST /api/auth/login`
- 逻辑：
  1. 根据用户名查找用户（`User.find_by_username`）
  2. 使用 `check_password_hash` 验证密码
  3. 检查账号是否激活（`is_active`）
  4. 生成 JWT access token，身份标识为用户 `ObjectId` 字符串

### 1.3 授权中间件
- 使用 `flask_jwt_extended.JWTManager` 进行 JWT 认证
- 路由使用 `@jwt_required()` 强制认证，`@jwt_required(optional=True)` 允许匿名访问
- 身份标识通过 `get_jwt_identity()` 获取，用于权限校验（如仅创建者可修改问卷）

## 2. 问卷生命周期逻辑

### 2.1 问卷状态机
```
draft (草稿) ──publish──> published (已发布) ──close──> closed (已关闭)
```

### 2.2 状态转换规则
| 当前状态 | 目标状态 | 条件 |
|---------|---------|------|
| draft | published | 问卷至少包含 1 道题目，操作者为创建者 |
| published | closed | 操作者为创建者 |
| 任意 | (删除) | 操作者为创建者，级联删除关联题目和回答 |

### 2.3 发布限制
- 已发布的问卷不能修改基本信息（标题、描述、设置）
- 已发布的问卷不能添加、修改、删除题目
- 已发布的问卷不能调整题目顺序
- 仅草稿状态可发布，仅已发布状态可关闭

### 2.4 访问链接
- 每个问卷创建时自动生成 8 位随机 `link_code`（UUID 前 8 位）
- 公开访问路径：`GET /api/surveys/link/<link_code>`
- 仅已发布状态的问卷可通过链接访问

## 3. 题目管理逻辑

### 3.1 支持的题型
| 类型 | 答案格式 | 需要选项 | 校验规则 |
|-----|---------|---------|---------|
| single_choice | 字符串 | 是 | 必须在选项中 |
| multiple_choice | 数组 | 是 | 每个元素必须在选项中，可限制 min/max/exact 选择数 |
| dropdown | 字符串 | 是 | 必须在选项中 |
| text | 字符串 | 否 | min_length, max_length, pattern |
| textarea | 字符串 | 否 | min_length, max_length, pattern |
| number | 数字 | 否 | min, max, integer_only |
| rating | 整数 | 否 | min, max |
| date | 字符串 (年-月-日) | 否 | 格式校验 |
| file | 字符串 (文件名) | 否 | 非空字符串 |

### 3.2 题目顺序
- 每个题目有 `order` 字段，在同一问卷内按 order 升序排列
- 新增题目时 order 自动设为现有题目数量
- 支持批量调整顺序（`reorder` 接口）

## 4. 跳转逻辑

### 4.1 跳转规则存储
跳转逻辑存储在 `questions.jump_logic` 字段中，不写死在代码：

```json
{
  "source_question_id": "题目ID",
  "condition": "equals|not_equals|contains|greater_than|less_than",
  "value": "比对值",
  "target_question_id": "目标题目ID",
  "action": "skip_to|hide|show"
}
```

### 4.2 条件判断
- `equals`: 答案字符串等于比对值
- `not_equals`: 答案字符串不等于比对值
- `contains`: 答案包含比对值（数组或字符串）
- `greater_than`: 答案数值大于比对值
- `less_than`: 答案数值小于比对值

### 4.3 动作语义
| 动作 | 含义 |
|------|------|
| skip_to | 跳转到目标题目，跳过中间题目 |
| hide | 条件满足时隐藏当前题目 |
| show | 条件满足时显示当前题目（默认隐藏） |

### 4.4 填写时的跳转处理
- 用户作答后，重新计算所有题目的可见性
- 根据 `source_question_id` 的答案判断是否触发跳转
- 触发 `skip_to` 时，直接跳转到目标题目
- 触发 `hide`/`show` 时，动态显示/隐藏题目

## 5. 答案校验逻辑

### 5.1 校验层次
- **前端**：实时必填校验，并在下一题/提交前校验多选题选择数量、文本字数、数字范围与整数要求
- **后端**：`ValidationService.validate_all()` 提交时全量校验

### 5.2 校验规则
| 题型 | 校验项 |
|------|--------|
| 所有题型 | required（必填） |
| single_choice/dropdown | 答案必须在 options 中 |
| multiple_choice | 答案元素必须在 options 中；min_select/max_select/exact_select |
| text/textarea | min_length, max_length, pattern（正则） |
| number | min, max, integer_only |
| rating | min, max |
| date | 格式 年-月-日 |
| file | 非空字符串 |

### 5.3 返回格式
```json
{
  "valid": true/false,
  "errors": {
    "question_id": "错误消息"
  }
}
```

## 6. 填写流程逻辑

### 6.1 开始填写
- 接口：`POST /api/fill/surveys/:id/start`
- 逻辑：
  1. 检查问卷状态为 published
  2. 若 `one_per_user` 为 true，检查用户是否已提交过
  3. 创建 `responses` 文档，状态为 `in_progress`
  4. 返回 response_id

### 6.2 保存草稿
- 接口：`PUT /api/fill/responses/:id/draft`
- 逻辑：更新 `answers` 字段，状态保持 `in_progress`

### 6.3 提交问卷
- 接口：`POST /api/fill/surveys/:id/submit`
- 逻辑：
  1. 获取当前 response 记录
  2. 调用 `QuestionService.validate_answers` 校验所有必填题
  3. 校验通过则更新状态为 `submitted`，记录 `submitted_at`
  4. 校验失败返回 422 及具体错误字段

### 6.4 匿名填写
- 未登录用户可填写，`user_id` 为 null
- 可通过 `settings.allow_anonymous` 控制是否允许匿名

## 7. 统计逻辑

### 7.1 问卷总览统计
- 总回答数：`responses` 集合中 status=submitted 的文档数
- 完成率：已提交回答数 / 已开始填写数
- 平均耗时：`submitted_at - started_at` 的平均值
- 每日趋势：按 `submitted_at` 日期分组聚合

### 7.2 单题统计
| 题型 | 统计内容 |
|------|---------|
| single_choice/dropdown | 各选项选择人数和百分比（饼图/柱状图） |
| multiple_choice | 各选项被选择次数（柱状图） |
| text/textarea | 所有填写内容列表 |
| number/rating | 平均值、最小值、最大值、中位数、分布区间（柱状图） |
| date | 各日期提交人数（柱状图） |

### 7.3 导出
- 支持 JSON、CSV、Excel 三种格式
- CSV 包含：response_id, user_id, submitted_at, 各题目答案
